RFID Door Lock Access Control System

Objective

To develop a low-cost electronic door security system using RFID technology.

Abstract

This project uses an Arduino UNO and an RC522 RFID reader to identify authorized RFID cards. When an authorized card is scanned, a servo motor unlocks the door temporarily. Unauthorized cards are denied access.

Hardware Requirements

- Arduino UNO
- RC522 RFID Reader
- RFID Card or Tag
- Servo Motor
- Jumper Wires
- Breadboard

Software Requirements

- Arduino IDE
- MFRC522 Library
- SPI Library
- Servo Library

Advantages

- Simple and low-cost security system
- Easy to operate
- Provides controlled access
- Can be expanded with additional security features

Conclusion

The project demonstrates how RFID technology can be used for electronic door access control.
