RFID Door Lock Access Control System

Introduction

This project uses RFID technology to control door access.

Components

- Arduino UNO
- RFID Reader (RC522)
- RFID Card or Tag
- Servo Motor
- Jumper Wires

Working Principle 

The RFID reader scans the card. If the card is authorized, the door lock opens. Otherwise, access is denied.

Applications

- Home Security
- Office Access Control
- Restricted Areas
